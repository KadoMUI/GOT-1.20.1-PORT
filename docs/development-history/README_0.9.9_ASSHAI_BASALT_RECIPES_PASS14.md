# Project Thrones 0.9.9 — Asshai / GOT Basalt Recipes Pass 14

Completes the missing base recipes for the existing Asshai basalt masonry chain.

Added / corrected:
- 4 Basalt Rock (2x2) -> 4 Basalt Bricks
- Smelt Basalt Bricks -> Cracked Basalt Bricks
- 2 Basalt Brick Slabs vertically -> 1 Carved Basalt Bricks
- 2 Basalt Bricks vertically -> 2 Asshai Basalt Pillars

The source already contained Asshai basalt stairs, slabs, walls, cracked variants,
and stonecutting recipes. Those existing recipes consume got:basalt_bricks /
got:cracked_basalt_bricks and are preserved unchanged.

No duplicate competing Asshai-brick base recipe is introduced.
No unrelated Basalt Gravel recipe is added.
