# GOT Iron / Alloy Steel Recipe Pass 3

Added to GOT faction crafting tables:
- Alloy Steel Hoe: standard vanilla hoe silhouette using Alloy Steel ingots.
- Iron Crossbow / Alloy Steel Crossbow: vanilla crossbow silhouette; available at every GOT faction table. Iron ingot selects Iron Crossbow, Alloy Steel ingot selects Alloy Steel Crossbow.
- Iron Mattock: shapeless Iron Pickaxe + Iron Shovel.
- Alloy Steel Mattock: shapeless Alloy Steel Pickaxe + Alloy Steel Shovel.
- Cross-tier mattock combinations do not match.
- Iron Throwing Axe / Alloy Steel Throwing Axe: `MM. / MS. / ...` (with normal shaped-recipe offsets/mirroring).
- Halberd intentionally remains without a recipe.
