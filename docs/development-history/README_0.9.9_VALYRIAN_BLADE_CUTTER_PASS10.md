# Valyrian Blade Cutter — Pass 10

Adds `got:valyrian_blade_cutter`, using the vanilla Stonecutter model and GUI.
Valyrian Steel weapon inputs convert 1:1 into registered Legendary Weapons of the matching physical weapon class via stonecutting recipes.

Mappings include Longsword, Sword, Greatsword, Dagger, Battle Axe, Crossbow and Hammer families. Gregor, Sandor and Beric are included as requested.

Note: this source does not contain an Oberyn-specific spear item ID, so no unrelated item was silently substituted for it.
