# Project Thrones 0.9.9 — GOT Iron / Alloy Steel Tools + Battle Axe Pass 2

Adds the standard tool recipes to the faction-table material weapon pass for GOT Iron and Alloy Steel.

## Standard tools
- Axe: standard vanilla axe silhouette (horizontal mirror accepted)
- Pickaxe: standard vanilla pickaxe silhouette
- Shovel: standard vanilla shovel silhouette

Iron recipes return the normal Minecraft iron axe/pickaxe/shovel. Alloy Steel recipes return `got:alloy_steel_axe`, `got:alloy_steel_pickaxe`, and `got:alloy_steel_shovel`.

## Battle Axe
Pattern:

```
MMM
MS.
.S.
```

Where M is the tier material and S is a stick. Applies to:
- `got:iron_battleaxe`
- `got:alloy_steel_battleaxe`

The faction crafting grid matcher preserves legacy horizontal mirroring and positional offsets.
