# Project Thrones 0.9.9 — Workstation Recipes Pass 12

Adds survival recipes for the remaining four functional workstations identified in the Pass 11 audit.

- Fermentation Barrel: 2 wheat + barrel + water bucket in the specified shaped pattern.
- Beacon: 3 log/wood blocks over 3 stone-family blocks.
- Command Table: 5 log/wood blocks over 3 stone-family blocks.
- Oven: furnace ring made from stone-family blocks with a Smoker in the center.

Wood slots use `minecraft:logs`, explicitly excluding planks.
Stone slots use `got:stone_materials`, currently accepting stone, cobblestone, andesite, diorite, granite, deepslate, cobbled deepslate, tuff, and blackstone.
