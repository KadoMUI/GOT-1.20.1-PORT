# Project Thrones 0.9.9 — Creature Fix Pass

- Added Barrow Wraith and Marsh Wraith spawn eggs to the Spawning creative tab.
- Rebuilt Giant/Wight Giant model geometry around the original 128x128 GOT Giant UV map.
- Centralized ice-undead vulnerability rules.
- Wights, White Walkers, and Wight Giants can be damaged by fire, Beric Dondarrion's sword, Obsidian/Dragonglass weapons, ordinary Valyrian weapons, all legacy legendary weapons whose 1.7.10 material was VALYRIAN_TOOL, and Petyr Baelish's dagger.
- Night King can only be damaged by Petyr Baelish's dagger.
