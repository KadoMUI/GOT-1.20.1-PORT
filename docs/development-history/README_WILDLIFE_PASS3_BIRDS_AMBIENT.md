# Wildlife Pass 3 — Birds & Small Ambient Wildlife

Restores legacy ambient wildlife: generic Bird family (COMMON/CROW/MAGPIE/SOTHORYOS), Seagull, Gorcrow, Butterfly family (COMMON/QOHOR/SOTHORYOS/ULTHOS), Flamingo, Swan and Midges. Uses legacy texture corpus and Planetos biome modifiers. Termites are intentionally deferred because their 1.7.10 implementation is hostile and tied to thrown-termite/animal-jar mechanics.
