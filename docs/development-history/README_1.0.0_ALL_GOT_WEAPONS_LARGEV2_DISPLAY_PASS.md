# Project Thrones 1.0.0 — All GOT Weapons Large-v2 Display Pass

Applies the Westeros Sword / Large-v2 display transform to all GOT weapon item models.

Explicit exclusions:
- All daggers
- Pickaxes, shovels, hoes, mattocks, chisels, crowbars, branding irons
- Blacksmith Hammer (utility tool)
- Crossbow pull-state submodels/projectiles

Textures, stats, recipes, combat classifications, and registry IDs are unchanged.

Weapon models updated: 136
