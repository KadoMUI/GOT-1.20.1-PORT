# Pacts Pass 4 — Shared Knowledge, Markers, Claims

- Pact-level persistent fast-travel knowledge: any member discovery becomes shared knowledge.
- Joining imports the member's existing unlocked regions and custom waypoints.
- Custom waypoints/map markers are shared with owner attribution, remain editable only by their creator, and disappear from the Pact when that member leaves/is kicked.
- Shared custom waypoints are valid fast-travel destinations for all Pact members.
- Banner claims automatically grant full claim access/edit/break permission to current Pact members of the banner owner. No manual whitelist entry is required.
- Fast-travel packet protocol bumped 18 -> 19 to transmit marker owner UUIDs.
