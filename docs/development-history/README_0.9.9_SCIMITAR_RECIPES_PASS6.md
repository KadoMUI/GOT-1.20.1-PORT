# Project Thrones 0.9.9 — Scimitar Recipe Pass 6

Scimitars now use the same recipe silhouette as Swords (2 matching material + stick)
and are produced only by explicit Essos faction crafting tables.

Covered material families where the scimitar item exists:
- Iron
- Alloy Steel
- Bronze
- Copper
- Gold
- Obsidian
- Stone
- Wood
- Valyrian Steel

Westeros tables continue to produce Swords. Summer Islands and Sothoryos are not
implicitly treated as Essos, preventing accidental Scimitar output there.
