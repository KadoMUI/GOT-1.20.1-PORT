# Material Weapon Recipes Pass 5

Adds Iron/Alloy-style recipes to registered Bronze, Copper, Gold, Obsidian,
Stone, Wood, and Valyrian Steel weapon/tool families.

Safety constraints:
- Scimitars are NOT implemented or modified.
- Halberds remain untouched.
- Recipes only return an item when that material/item ID is actually registered.
- Mattocks require matching-material pickaxe + shovel.
- Wood uses any planks-tag item.
- Poisoned daggers retain the shapeless dagger + poison route.
