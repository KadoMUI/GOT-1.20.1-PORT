# Special Mobs Pass 1 — Stone Men & Werewolves

Restores the legacy Stone Man and Werewolf as dedicated hostile mobs.

- Stone Man: legacy 20 HP, 0.22 speed, 5 damage, Valyria weight 5, darkness spawning, no normal drops, wither/stone affliction on successful melee hits. Uses the existing eight male/eight female legacy Stone Man skins.
- Werewolf: legacy 40 HP, 0.22 speed, 5 damage, Mossovy/Mossovy Taiga weight 5, darkness spawning, 1–3 leather plus looting bonus, wolf/direwolf-style sounds. Uses the existing legacy werewolf texture.
- Both are registered as MONSTER entities with modern melee/wander/target AI and natural Planetos biome modifiers.
