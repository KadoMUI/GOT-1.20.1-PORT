# Contributing to Conquest of Westeros

## Bug reports

Please include:

- Conquest of Westeros version
- Minecraft version
- Forge version
- Singleplayer or dedicated server
- Reproduction steps
- `latest.log` and/or the relevant crash report

Do not upload entire game instances unless specifically requested.

## Pull requests

Keep pull requests focused on one feature or fix. Test the change in a clean development instance before submission.

Do not commit:

- `build/`
- `.gradle/`
- `run/`
- IDE metadata
- logs or crash reports
- locally generated test worlds

Historical porting/audit documents are retained under `docs/`; new development notes should not be added to the repository root.
